# 类浏览器层级树与锚点停靠交互改造 Spec

## Why
当前类/方法浏览以"平铺列表 + 点击即弹出独立窗口"为主：层级关系不直观、窗口数量迅速膨胀、列表滚动无惯性不够顺手，触摸端难以同时对照"类列表"与"某类的方法列表"。需要把浏览交互重做成层级树 + 标签卡 + 锚点停靠的形式。

## What Changes
- 类列表由平铺改为**可折叠层级树**：类名与方法名前都有展开/折叠箭头；方法作为类节点子项，并可继续二级展开（重载/参数/详情），**不再点击即新开独立窗口**
- 展开项可**钉选为顶部选项卡标签**（放入现有顶部 TabBar），再次点击即可从选项卡收回
- 标签卡可**脱离为独立浮动窗口**，也可**回归**选项卡
- 引入**停靠机制**：标签卡可拖拽脱离成窗口；长按拖拽到**预设锚点**（单列 / 双列左列表右内容 / 双列左右内容 / 三列）快速成布局
- 列表滚动改为**带惯性的平滑滚动**（记录拖拽速度，松手后逐帧衰减）
- **层级视觉优化**：缩进引导线、层级配色、hover/选中态、折叠状态记忆

**关键技术结论（已核实）**：本工程 ImGui 源中 `IMGUI_HAS_DOCK` 从未定义，`imgui.h` 无 `DockSpace`/`DockBuilder`/`IsWindowDocked` 声明（仅 `imgui_internal.h`、`imgui.cpp` 有残留条件编译块）。故**不采用**"切换到 ImGui docking 分支"方案（需整体替换 imgui 源，与现有 1.92 字体缩放等改动冲突、风险高），改为实现**预设锚点布局**——触摸端也比自由停靠更易操作。

## Impact
- Affected specs: 类浏览器（ClassesTab）、菜单主布局与顶部选项卡（ImGui.cpp）、触摸输入与滚动（ImGui.cpp）、多语言文案（Lang）
- Affected code:
  - `app/src/main/jni/Tool/ClassesTab.cpp` / `ClassesTab.h`（层级树、就地展开、钉选、方法子节点）
  - `app/src/main/jni/Menu/ImGui.cpp` / `ImGui.h`（顶部 TabBar 承载钉选标签、浮动窗口、锚点布局、惯性滚动）
  - `app/src/main/jni/Tool/Lang.cpp`（新增 UI 文案，含 zh-TW）
  - 复用现有 `ConfigSet/ConfigGet` 持久化布局与折叠状态
- 不改动：ImGui 第三方源码（不替换为 docking 分支）

## ADDED Requirements

### Requirement: 层级树就地展开
系统 SHALL 在类列表中用可折叠树呈现类与其成员，类名与方法名前显示展开/折叠箭头，展开发生在列表内部而不是新开窗口。

#### Scenario: 展开一个类查看方法
- **WHEN** 用户点击类名前的展开箭头
- **THEN** 该类在列表中就地展开并显示其方法子节点，且不创建新窗口
- **AND** 再次点击同一箭头则折叠

#### Scenario: 展开一个方法查看详情
- **WHEN** 用户点击方法名前的展开箭头
- **THEN** 该方法在类节点下就地展开显示参数/返回类型等详情

### Requirement: 钉选为选项卡标签
系统 SHALL 允许把已展开的类钉选为顶部选项卡栏中的一个标签，并可再次点击取消钉选收回。

#### Scenario: 钉选类为标签
- **WHEN** 用户点击某类节点旁的钉选按钮
- **THEN** 顶部选项卡栏出现该类的标签并成为当前标签，该类在树中显示为已钉选态

#### Scenario: 取消钉选
- **WHEN** 用户再次点击同一类的钉选按钮
- **THEN** 该标签从选项卡栏移除，树中钉选态消失

### Requirement: 标签卡脱离与回归
系统 SHALL 支持把标签卡脱离为独立浮动窗口，并可从浮动窗口回归选项卡。

#### Scenario: 脱离为浮动窗口
- **WHEN** 用户点击标签卡上的"弹出"操作
- **THEN** 该类内容改为在可拖动、可缩放的独立窗口中渲染，且从选项卡栏移除

#### Scenario: 回归选项卡
- **WHEN** 用户点击浮动窗口上的"回归"操作
- **THEN** 该类内容重新作为标签卡加入顶部选项卡栏，浮动窗口关闭

### Requirement: 预设锚点停靠
系统 SHALL 提供预设锚点布局，拖拽标签卡时高亮最近锚点，松手后切换为该布局并放置目标。

#### Scenario: 拖到左侧锚点成双列
- **WHEN** 用户长按拖拽一个标签卡到窗口左侧锚点区域并松手
- **THEN** 布局切换为双列：左侧为类名列表区、右侧为该类的内容区

#### Scenario: 锚点预览
- **WHEN** 拖拽过程中指针靠近某个锚点
- **THEN** 该锚点区域显示高亮预览，离开则取消高亮

### Requirement: 惯性平滑滚动
系统 SHALL 使列表滚动带惯性：拖拽时记录速度，松手后逐帧衰减直到停止。

#### Scenario: 快速滑动后减速
- **WHEN** 用户在类列表上快速滑动并松手
- **THEN** 列表继续平滑滚动并逐渐减速停止，而非立即静止

### Requirement: 层级视觉呈现
系统 SHALL 通过缩进引导线、层级配色与 hover/选中态区分层级，并记忆折叠状态。

#### Scenario: 折叠状态记忆
- **WHEN** 用户折叠某类后关闭并重新打开菜单
- **THEN** 该类仍保持折叠状态

## MODIFIED Requirements

### Requirement: 类列表渲染
类列表渲染由"平铺列表 + 独立窗口展示类详情"改为"层级树就地展开；方法详情以展开子节点/卡片呈现；独立窗口仅由用户显式钉选或脱离产生"。

## REMOVED Requirements

### Requirement: 点击类即弹出独立窗口
**Reason**: 与就地展开交互冲突，导致窗口数量爆炸、层级关系丢失。
**Migration**: 由"就地展开 → 钉选为选项卡标签 → 脱离为浮动窗口"三级机制替代；原方法卡片中的调用/修改/追踪能力保留在展开后的方法子节点内。
